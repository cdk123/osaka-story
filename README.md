# 🏮 알면 맛있는 오사카 (`osaka-story`)

친구에게 옛날이야기 들려주듯 알려주는 **오사카 음식·역사·골목·장인·생존팁 범용 웹 매거진 & 스마트 가이드북** 프로젝트입니다.

## 📂 정본 문서 안내

* **[전체 기획 대화 기록 및 마스터 원고 (`CHAT_HISTORY_FULL.md`)](CHAT_HISTORY_FULL.md)**
  * 1차~8차 기획 대화 원문 100%, 시대별 역사 스토리텔링(프롤로그~제6장), 맛집·명소·장인 명품 50+곳 리스트(한글+일본어 원어 병기), 오사카 사투리 10선, 배경 영화·애니·소설, 인생샷 포토존, 오사카 도시 백과(부산 비교·6대 구역·3대 시장·특산물), 공항·대중교통·표지판·예절 생존 가이드, 5대 탭 UI/UX 및 GitHub + Cloudflare 배포 아키텍처가 모두 수록되어 있습니다.

## 🚀 구축 핵심 요건 요약

1. **기술 스택**: 순정 Astro (정적 빌드 SSG) + 모바일 퍼스트 반응형 웹(PWA) + GitHub 리포지토리 + Cloudflare 배포
2. **디자인 테마**: ‘오사카 나니와(浪華) 모던 에디토리얼’ (`#FBF8F3` 화지 배경, `#D63B22` 나니와 주홍, `#1E293B` 남색 노렌 헤더, 나무 명패 탭, 붉은 낙관 뱃지, 팔백팔교 파도 디바이더, 한글 `Pretendard` + 일본어 `Shippori Mincho`/`Noto Sans JP`)
3. **5대 핵심 탭**:
   * `🗺️ 오사카 한눈에`: 부산 비교 면적·인구, 6대 구역(키타·미나미 등) 지도, 3대 시장 & 특산물
   * `📖 미식·역사 이야기`: 프롤로그 ~ 제6장 스토리북 (중간에 인터랙티브 가게·명소 카드 삽입)
   * `🔍 맛집·명소 찾기`: 권역 × 카테고리 × 동행자(부모님·대가족 5인석 / 1020 청춘 / 어른 술자리 / 혼밥) 필터
   * `🚇 초보 생존·사투리`: 간사이공항→시내 이동, 지하철·버스·택시 요령, 노렌·표지판 해독, 식당 예절 6계명, 실전 오사카 사투리 10선 플립 카드, 영화·애니·소설 4선
   * `♥ 내 찜 바구니`: `localStorage` 찜 저장 + 권역별 동선 자동 그룹핑 + URL 파라미터(`?picks=...`) 기반 카카오톡 공유 링크 생성
4. **개별 장소 카드 필수 기능**:
   * 고화질 대표 실사 사진 + 구글맵 현지 매장 사진·리뷰·길찾기 직결 미리보기 조합
   * 한글 상호명 + 일본어 원어 상호명 + 한글 발음 3단 표기
   * `[📍 구글지도 길찾기]` 딥링크 & `[🚕 기사님·현지인 보여주기]` 전체화면 모달
